OKK NOVI PAZAR / UPRAVLJANJE

Objavljuj vesti i rezultate preko telefona

Za uređivanje koristimo besplatni Pages CMS. Prijava je za vlasnika GitHub repozitorijuma sajta.

OTVORI ADMIN PANEL ↗

  1. Prijavi se svojim GitHub nalogom.
  2. Izaberi repozitorijum OKK Novi Pazar koji si prethodno povezao.
  3. Uredi „Vesti“, „Utakmice“, „Igrači“ ili „Tekstovi“ i klikni Sačuvaj.
  4. Kada je repozitorijum povezan sa Netlify sajtom, ažuriranje se automatski objavljuje.

Važno: samo postavljanje ZIP fajla na Netlify ne aktivira automatsko objavljivanje. Potrebno je jednokratno povezivanje GitHub repozitorijuma sa postojećim Netlify projektom.
